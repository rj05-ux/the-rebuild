# Personal Expense Tracker — Python Fundamentals Capstone

A simple command-line app to add, view, and delete personal expenses, with data saved locally so it persists between runs. Built as the capstone project for the Python Fundamentals track, pulling together loops, functions, conditionals, exception handling, and file I/O into one working tool.

## What it covers

- Loops and conditionals for the menu system
- Functions for each action (add, view, delete)
- Exception handling for invalid input
- File I/O (JSON) for saving and loading expenses between runs

## Problem statement

Build a command-line expense tracker that can:

1. Add an expense with a category, amount, and date
2. View all expenses recorded so far, with a running total
3. Delete an expense that's no longer needed
4. Save expenses to a local file, so nothing is lost when the program closes

## How to run it

```bash
python main.py
```
