# Number-Guessing Game

A command-line game that picks a random number and lets the player keep guessing until they get it right.

## Why

To practice `while` loops, conditionals, comparison operators, and a counter variable.

## What it does

- Picks a random number in a set range (1-100)
- Asks for a guess in a loop
- Tells the player "Too high" or "Too low" after each wrong guess
- Counts the attempts
- Ends only when the correct number is guessed, then prints the number of attempts
