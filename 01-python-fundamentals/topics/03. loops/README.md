# Number-Guessing Game

A command-line game that picks a random number and lets the player keep guessing until they get it right built to practice `while` loops, conditionals, and basic comparison operators.

## What it does

- Picks a random number in a set range (e.g., 1–100)
- Loops repeatedly, asking for a guess each time
- Tells the player "Too high" or "Too low" after each wrong guess
- Tracks and prints the number of attempts once the player guesses correctly
- The loop only ends when the correct number is guessed

## How to run it

Run `number_guessing_game.py` in any Python environment. Each run generates a new random number, so no two playthroughs are the same.
