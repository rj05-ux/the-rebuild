# Expense Tracker (Basic Version)

A simple command-line script that records one expense entry, demonstrates basic category matching, and calculates a running total from repeated amount inputs.

## What it does

- Prompts for a single expense: category, amount, and date

- Checks if a given "category to delete" matches part of the entered category, and removes it if found

- Then runs a loop asking for amounts repeatedly, adding each one to a running total, until you enter 0 to stop

- Prints the final total when you're done

## How to run it

```bash

python main.py

```

## Note

This is an early version focused on practicing loops, conditionals, string handling, and basic input validation. It does not yet store multiple expenses as a list or save data to a file — that's the planned next step for this project.
